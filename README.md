# 🚀 Shell Script Collection by Yash Gondaliya

A powerful collection of **Bash/Shell scripts** designed to automate system tasks, user management, file handling, and learning concepts.

---

## 📂 Project Structure

```
.
├── backup.sh              # Backup files
├── new_backup.sh          # Improved backup script
├── move_all_file.sh       # Move files between directories
├── package_install.sh     # Install packages automatically
├── create_user.sh         # Create new system user
├── delete_user.sh         # Delete system user
├── another_user.sh        # User-related operations
├── function.sh            # Functions in shell scripting
├── loops.sh               # Loop examples
├── while_loop.sh          # While loop example
├── hello_chatur.sh        # Fun script 😄
├── 3_idiots.sh            # Movie-based script 🎬
├── demo.txt               # Demo file
├── from_dev.txt           # Dev file
├── from_remote.txt        # Remote file
├── help                   # Help/guide script
└── README.md
```

---

## ⚡ Features

- 🛠️ System automation scripts  
- 👤 User management (create/delete users)  
- 📦 Package installation automation  
- 🔁 Loop & function examples (for learning)  
- 📂 File handling utilities  
- 🎯 Beginner-friendly scripts  

---

## 🧑‍💻 Requirements

- Linux / Ubuntu / WSL  
- Bash Shell  

---

## ⚙️ Setup

Clone the repository:

```bash
git clone https://github.com/yashgondaliy/shell-scripts.git
cd shell-scripts
chmod +x *.sh
```

---

## ▶️ Usage

Run any script:

```bash
./script-name.sh
```

### Example

```bash
./backup.sh
./create_user.sh
./package_install.sh
```

---

## ⚠️ Notes

- Some scripts may require **sudo/root access**  
- Always review scripts before executing  
- Use in a safe/test environment first
